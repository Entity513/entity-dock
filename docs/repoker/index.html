オペレーションシステム

受付 → プレイ管理 → 精算の一貫した流れ

全体像（思想）

この仕組みの本質は、① 来店者の重複・誤処理を防ぐこと、 ② トーナメントとリングを明確に分離して管理すること、 ③ 人為ミスが起きやすい「お金の動き」を紙＋スプレッドシートで二重管理することにある。

アナログ（紙）とデジタル（Poker Fans／スプレッドシート）を意図的に併用している点が肝。

このオペレーションの強みと弱点

冷静な評価による、現実的な運用指針

強み

✓

人がミスしやすい部分（お金・名前）を
紙 × 自動表示 × 二重確認で潰している

✓

トーナメントとリングを完全に切り分けているため
収支・トラブルが混線しにくい

✓

システム未完成でも即日回せる現実解

弱点

⚠

紙管理はオペレーション教育が甘いと破綻する

⚠

フロアの記入精度が低いと全体が崩れる

この仕組みは「雑にやると破綻、丁寧にやるとかなり強い」タイプ。
思想は正しい。あとは現場教育の徹底だけ。

「記入はフロアが行う」「その場で書く」
という原則は絶対に崩さない前提。
